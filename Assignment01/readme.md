🚀 Python Projects
This repository contains various Python projects, exercises, and solutions that demonstrate common concepts such as loops, conditionals, and functions.

1. High-Low Game
Problem Statement:
In this game, you and the computer are assigned random numbers, and the player has to guess if their number is higher or lower than the computer's. A point is awarded if the player guesses correctly.

Solution Overview:
Generates a random number for the player and the computer.

The player guesses whether their number is higher or lower than the computer's number.

After each round, the player's score is updated based on correct guesses.

2. Planetary Weight Calculator
Problem Statement:
This program calculates the equivalent weight on different planets based on the user's weight on Earth. The user can input their weight and choose a planet, and the program will calculate and print the corresponding weight on the selected planet.

Solution Overview:
The user enters their weight on Earth.

The program prompts the user to enter a planet (e.g., Mars, Venus, Jupiter, etc.).

Based on the planet selected, the program calculates and prints the equivalent weight on that planet.

3. Countdown Timer
Problem Statement:
This program simulates a countdown timer for a spaceship launch. It counts down from 10 to 1 and then outputs "Liftoff!" when the countdown finishes.

Solution Overview:
Uses a for loop to countdown from 10 to 1.

After reaching 1, it prints "Liftoff!" to signal the completion of the countdown.

4. Double a Number
Problem Statement:
This program asks the user for a number and then repeatedly doubles it, printing the result each time, until the value is 100 or greater.

Solution Overview:
The program initializes the number entered by the user.

It uses a while loop to double the number until it is 100 or greater, printing the result each time.

5. Guess My Number
Problem Statement:
In this game, the program thinks of a secret number between 0 and 99, and the user has to guess it. The program provides hints if the guess is too high or too low until the user guesses the correct number.

Solution Overview:
A random number between 0 and 99 is generated.

The user is asked to input guesses, and the program provides feedback ("too low" or "too high").

The loop continues until the user guesses the correct number.

6. Random Number Generator
Problem Statement:
This program prints 10 random numbers between 1 and 100. Each time the program is run, the numbers should be different.

Solution Overview:
The program generates 10 random numbers between 1 and 100 using the random.randint() function.

It prints each random number on a new line.
